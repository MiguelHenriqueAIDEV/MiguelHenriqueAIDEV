# Technical Learning Roadmap

This roadmap separates **current practical experience** from **next learning priorities** for technology internship preparation.

It is not a claim of proficiency in every item below. The goal is to document what I am actively strengthening next.

## Current practical base

Projects in this portfolio already demonstrate work with:

- Python fundamentals through a desktop automation project;
- Tkinter and PyAutoGUI;
- process automation;
- AI-assisted development;
- prompt engineering;
- HTML and CSS;
- cloud deployment with Cloudflare;
- webhook and event-driven automation concepts;
- idempotency and persistent state in integration workflows;
- testing, debugging and iterative refinement.

## Priority 1 — Python foundations

Continue strengthening:

- functions and modules;
- data structures;
- exceptions;
- file handling;
- object-oriented programming;
- package management;
- automated testing basics;
- clean-code practices.

### Portfolio target

Build at least one additional Python project with automated tests and a clear problem / solution structure.

## Priority 2 — SQL and relational data

Learn and practice:

- `SELECT`;
- filters;
- sorting;
- joins;
- aggregations;
- grouping;
- basic schema design;
- primary and foreign keys.

### Portfolio target

Create a small project that reads or writes structured data through SQL rather than only JSON / local configuration.

## Priority 3 — Git workflows

Strengthen practical use of:

- commits;
- branches;
- pull requests;
- merge workflows;
- conflict resolution;
- `.gitignore`;
- code review habits.

### Portfolio target

Use feature branches and pull requests for future portfolio improvements instead of committing every change directly to `main`.

## Priority 4 — APIs and backend fundamentals

Study and practice:

- HTTP methods;
- JSON payloads;
- REST APIs;
- status codes;
- authentication concepts;
- environment variables;
- webhook verification concepts;
- basic backend endpoints.

### Portfolio target

Build a small Python API or integration project with documented requests, responses and error handling.

## Priority 5 — Data and BI fundamentals

Develop an introductory base in:

- data cleaning;
- simple analysis with Python;
- spreadsheet automation;
- dashboards;
- Power BI or a similar visualization tool.

This is useful for internships that combine technology, analytics and automation.

## Priority 6 — Technical English

Improve comfort with:

- reading documentation;
- explaining projects in English;
- technical interview vocabulary;
- writing concise technical documentation;
- participating in basic engineering conversations.

## Optional specialization — RPA / low-code automation

Explore tools such as:

- Power Automate;
- UiPath;
- similar workflow / RPA platforms.

This is a secondary path that complements the automation work already present in the portfolio.

## Portfolio principles

For every new project:

1. define the problem;
2. document requirements;
3. build a working implementation;
4. test it;
5. document limitations honestly;
6. include setup instructions;
7. avoid exposing credentials or private data;
8. publish only features that actually exist;
9. explain where AI assisted the development process;
10. keep the repository easy to understand in a few minutes.

## Goal

Build a portfolio that demonstrates progression from **AI-assisted prototyping** toward stronger **software engineering, automation, data and integration fundamentals**.
